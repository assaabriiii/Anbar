Keep building when the internet goes dark.

وقتی اینترنت قطع است، کارتان متوقف نشود.

Anbar scans your project, downloads every dependency while the internet works, and serves it as local mirrors later. pip, npm, docker and Hugging Face keep working through shutdowns and filtering.

انبار پروژهٔ شما را بررسی می‌کند، تا وقتی اینترنت وصل است همهٔ وابستگی‌ها را دانلود می‌کند و بعداً آن‌ها را به شکل میرورهای محلی سرو می‌کند. pip، npm، docker و Hugging Face در قطعی و فیلترینگ هم کار می‌کنند.

Why Anbarچرا انبار

Built for shutdowns, filtering and slow links

ساخته‌شده برای قطعی، فیلترینگ و اینترنت کند

Anbar (انبار) means "storehouse" in Persian. When PyPI, npm, Docker Hub and Hugging Face are blocked for days, the kit you packed earlier still has everything your project needs.

«انبار» برای روزهایی ساخته شده که PyPI، npm، Docker Hub و Hugging Face در دسترس نیستند. کیتی که از قبل ساخته‌اید همهٔ نیازهای پروژه را در خود دارد.

Finds everything

همه‌چیز را پیدا می‌کند

Lock files, requirements, pyproject, Dockerfiles and compose files are detected on their own, including transitive dependencies and multi-stage base images.

lock فایل‌ها، requirements، pyproject، Dockerfileها و فایل‌های compose خودکار پیدا می‌شوند؛ همراه با وابستگی‌های غیرمستقیم و ایمیج‌های بیلد چندمرحله‌ای.

Incremental and resumable

افزایشی و ادامه‌پذیر

Parallel downloads with retries continue where they stopped. Running pack again only fetches what changed.

دانلودهای موازی با تکرار خودکار از همان‌جا که قطع شده‌اند ادامه پیدا می‌کنند. اجرای دوبارهٔ pack فقط موارد تازه را می‌گیرد.

Verified by default

همیشه بررسی‌شده

Every file is checked against its sha256 or SRI hash. TLS verification can't be turned off, and no credentials are ever stored in a kit.

هر فایل با هش sha256 یا SRI بررسی می‌شود. بررسی TLS خاموش‌شدنی نیست و هیچ رمز یا توکنی در کیت ذخیره نمی‌شود.

Upstream mirrors

میرورهای بالادستی

Download through local PyPI, npm, Docker Hub and Hugging Face mirrors, tried in order, or through an HTTP or SOCKS proxy.

از میرورهای داخلی PyPI، npm، Docker Hub و Hugging Face (به ترتیب اولویت) یا از پراکسی HTTP و SOCKS دانلود کنید.

Reversible setup

تنظیمات برگشت‌پذیر

anbar use backs up every config file it touches. anbar restore puts them all back exactly as they were.

anbar use پیش از هر تغییر از فایل‌های تنظیمات پشتیبان می‌گیرد و anbar restore همه را دقیقاً به حالت قبل برمی‌گرداند.

Cross-platform kits

کیت برای هر سیستم‌عامل

Develop on Windows and deploy to Linux? Pack wheels for other platforms and Python versions, and images for other architectures.

روی ویندوز توسعه می‌دهید و روی لینوکس دیپلوی می‌کنید؟ wheel برای پلتفرم‌ها و نسخه‌های دیگر پایتون و ایمیج برای معماری‌های دیگر بگیرید.

How it worksروش کار

Five minutes, two moments

پنج دقیقه، در دو زمان

Pack while you're online, then serve and use the kit when you're not, on the same machine or another one.

وقتی آنلاین هستید کیت را بسازید؛ وقتی آفلاین شدید، روی همان سیستم یا سیستمی دیگر، آن را سرو و استفاده کنید.

With internetبا اینترنت

Install Anbar

انبار را نصب کنید

pipx install anbar

See what your project needs

ببینید پروژه چه لازم دارد

cd my-project
anbar scan

Pack the kit

کیت را بسازید

anbar pack --out ~/anbar-kit
anbar verify ~/anbar-kit   # optional
Without internetبدون اینترنت

Start the local mirrors

میرورهای محلی را روشن کنید

anbar serve ~/anbar-kit

Point your tools at them

ابزارها را به آن‌ها وصل کنید

anbar use ~/anbar-kit
pip install -r requirements.txt
npm ci
docker compose build

Undo it all when you're back online

وقتی اینترنت برگشت، همه‌چیز را برگردانید

anbar restore

For teamsبرای تیم‌ها

One person with internet can supply everyone

یک نفر با اینترنت، نیاز همهٔ تیم را تأمین می‌کند

A kit is an ordinary folder. Carry it on a USB drive, or serve it to the whole office over the LAN.

کیت یک پوشهٔ معمولی است. آن را روی فلش جابه‌جا کنید یا در شبکهٔ محلی برای کل دفتر سرو کنید.

USB driveفلش

anbar export team-kit --to /media/usb/team-kit.tar
# on every other machine
anbar import /media/usb/team-kit.tar --to ~/team-kit

The archive comes with a sha256 file, so a damaged copy is caught before you use it. Importing a newer export only adds new files.

آرشیو یک فایل sha256 همراه دارد تا کپی خراب پیش از استفاده شناسایی شود. import یک خروجی جدیدتر فقط فایل‌های تازه را اضافه می‌کند.

Local networkشبکهٔ محلی

anbar serve ~/team-kit --host 0.0.0.0
# on every teammate's machine
anbar use --host 192.168.1.10

Teammates don't need a copy of the kit. Their pip, uv, npm, yarn and pnpm point straight at your machine.

هم‌تیمی‌ها به نسخه‌ای از کیت نیاز ندارند؛ pip، uv، npm، yarn و pnpm آن‌ها مستقیم به سیستم شما وصل می‌شوند.

Pack your kit before you need it

کیت را پیش از آنکه لازمش داشته باشید بسازید

Anbar installs offline too. Every release ships a single-file .pyz and a wheel bundle for Linux, macOS and Windows.

خود انبار هم آفلاین نصب می‌شود. هر ریلیز یک فایل تکی .pyz و یک بستهٔ wheel برای لینوکس، مک و ویندوز دارد.
